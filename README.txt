VARUNAPATH AI — QUICK START
Team Novara

OPTION 1 (EASIEST)
1. Extract the downloaded ZIP file.
2. Open the extracted VarunaPath_AI folder.
3. Double-click START_VARUNAPATH.bat.
4. Wait for the browser dashboard to open.

OPTION 2 (COMMAND PROMPT)
1. Open Command Prompt inside this folder.
2. Run: python -m pip install -r requirements.txt
3. Run: python -m streamlit run app.py

TO STOP
Return to the Command Prompt and press Ctrl+C.

IMPORTANT
This is a functional proof of concept using simulated maritime data.
It does not make real vessel bookings or use confidential enterprise data.
